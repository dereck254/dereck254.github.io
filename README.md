# Derek Rawlings Ongaro — Personal Website

A responsive static personal website designed for GitHub Pages. It intentionally omits a precise location and does not publish a private address or personal phone number.

## Before publishing

1. Open `index.html` and replace the placeholder `#` links in the Contact section with your actual public LinkedIn, X, and GitHub profile URLs. Remove any networks you do not want to show.
2. Review the biography and experience wording for accuracy.
3. Do not add private contact details or your home address.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io` (replace the placeholder with your GitHub username).
2. Upload `index.html`, `styles.css`, `script.js`, and `favicon.svg` to the repository root. You can also upload `README.md`.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for the deployment to finish. Your site will be at `https://YOUR-GITHUB-USERNAME.github.io/`.
6. Test the website on your phone and desktop. Keep in mind that public repositories and websites are visible to everyone.

## Editing later

Edit `index.html` for wording and links; edit `styles.css` for design; edit `script.js` for small interactive behavior.
